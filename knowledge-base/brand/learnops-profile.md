# LearnOps Brand Profile & Core Directive

### Core Educational Directive & Invariant
> **The owner's only routine responsibility is maintaining the LearnOps course content and the General DevOps knowledge base. The system must independently discover topics, generate Reel ideas, rank them, maintain the backlog, and select content for daily production. The owner must never be required to manually suggest or prompt Reel ideas.**

### Brand Identity
- **Platform:** LearnOps (`www.learnops.dev`) - Hands-on interactive Linux and DevOps learning with browser-based Ubuntu labs and automated task validation.
- **Voice & Tone:** Practical, punchy, technically rigorous, encouraging, visually clear, and zero-fluff.
- **Visual Aesthetic:** Dark obsidian theme (`#110F17`) with brand violet/purple accent (`#783CEB`), clean monospace code blocks, and dynamic motion graphics.
- **Target Audience:** Junior to mid-level software developers, sysadmins, DevOps engineers, and CS students moving from passive video watching to real hands-on systems knowledge.
- **Core Educational Value:** Demystify system internals (why things work, not just memorizing commands).
